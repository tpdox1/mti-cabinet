# МТИ · личный кабинет студента

Учебный сайт на Flask для «Московского технологического института»: главная страница, регистрация, вход и личный кабинет студента с фотографией.

## Что умеет

- регистрация по email и паролю;
- пароль хранится как хэш, а не открытым текстом;
- вход и выход из аккаунта;
- CSRF-защита POST-форм и безопасные session cookie;
- профиль: имя, фамилия, город, дата рождения, телефон, текст «о себе»;
- загрузка фотографии JPG/JPEG/PNG/WebP до 5 МБ;
- фотография хранится прямо в БД вместе с данными профиля;
- локально работает на SQLite;
- на сервере можно подключить PostgreSQL через `DATABASE_URL`.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

Открыть: http://127.0.0.1:5000

## PostgreSQL на сервере

Создай базу и укажи переменные окружения:

```env
SECRET_KEY=очень-длинная-случайная-строка
DATABASE_URL=postgresql://username:password@localhost:5432/study_site
```

Запуск production-сервера:

```bash
gunicorn -w 2 -b 0.0.0.0:8000 app:app
```

После этого Nginx можно направить на `127.0.0.1:8000`.

## Фотографии

Для простоты учебного проекта фотография хранится прямо в базе данных (`LargeBinary`; в PostgreSQL это `bytea`). Поэтому она не пропадёт при перезапуске приложения или при использовании хостинга с временной файловой системой. Для большого production-проекта фотографии обычно выносят в объектное хранилище, но для этого проекта вариант с БД удобнее.

## Быстрый деплой

В проект добавлены `Dockerfile` и `Procfile`. На сервере достаточно задать `SECRET_KEY`, `DATABASE_URL` и при HTTPS `COOKIE_SECURE=1`, затем запустить приложение через Gunicorn или Docker. Домен не обязателен: можно использовать IP сервера или адрес, который выдаст хостинг.
